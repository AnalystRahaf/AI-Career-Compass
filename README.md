# AI-Career-Compass
AI Career Compass is a bilingual (English/Arabic) career insights platform for Data &amp; AI roles that predicts salaries and provides personalized guidance on the best roles, countries, and skills to grow your career.

Technologies:
- Python
- Flask
- Scikit-learn
- Power BI
- HTML
- CSS
- JavaScript

Model Performance:
- R² = 0.895
- MAE ≈ 12985 USD
